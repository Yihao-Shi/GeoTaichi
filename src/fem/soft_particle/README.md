# Deformable Soft-Particle Contact in Finite Element–Discrete Element Mechanics

This directory contains the FEM-child implementation used by soft-particle
contact workflows. The bulk body remains an ordinary TET4 or HEX8 FEM
discretization; only its extracted boundary participates in contact.

The theory, supported contact branches, search invariants, and setup examples
are maintained in the
[FEDEM soft-particle documentation](../../fedem/README.md#soft-particle-contact).
